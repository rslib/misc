# rslib-misc

Small shared pieces for rslib projects that do not need their own repository.

| Folder                    | What it holds                               |
| ------------------------- | ------------------------------------------- |
| [`starlight/`](starlight) | The Starlight docs theme for rslib projects |

## Quickstart

See the Starlight theme on a sample rgit site:

```sh
cd starlight/example
npm install
npm run dev
```

Open http://localhost:4321.
For a look without a server, open `starlight/preview.html` in a browser.
